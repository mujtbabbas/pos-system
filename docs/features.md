# Features

An expanded overview of what this POS system does, based on the feature set described in the [README](../README.md).

## Sales and invoicing

- Fast checkout flow designed for daily retail use
- Dynamic invoice generation for each sale

## Inventory management

- Real-time stock tracking as items are sold
- Low-stock alerts so items can be reordered before they run out

## Reporting

- Sales reports for daily, weekly, and monthly periods
- Visibility into stock levels and sales performance across the business

## User management

- Role-based access control
- Separate roles for cashiers and administrators, so staff only see the functions their role needs

## Technology

- Backend: Core PHP
- Database: MySQL
- Frontend: HTML5, CSS3, and JavaScript, using AJAX for seamless interactions
